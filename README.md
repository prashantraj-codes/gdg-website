# GDG Campus Events 🌐

A simple, responsive event website created for the **GDG on Campus IIIT Kalyani Core Team Recruitment - Phase 2**.

---

## 📌 About the Project

This website presents a campus technology event , workshops and provides a simple registration form interface. It is designed to be clean, modern, and easy to navigate on both desktop and mobile devices.

---

## ✨ Features

* **Navigation Bar**: Includes the GDG on Campus • IIIT Kalyani branding, section links (About, Schedule, Highlights), and an IIIT Kalyani badge button.
* **Hero Section**: Features the tagline "LEARN. BUILD. CONNECT." along with a descriptive overview of IIIT Kalyani's premier Google Developer Groups flagship event.
* **Event Details**: Quick-view badges for **Date** (To be confirmed) and **Venue** (IIIT Kalyani).
* **Interactive Registration Form**: A "Register Your Interest" card capturing Name, Email, and Branch (e.g., CSE, ECE) with a "Register Now" action button.
* **What to Expect Section**: Highlights core event offerings including:
  * **Tech Talks**: Sessions on Web Development, Cloud, and AI/ML by senior developers.
  * **Hands-on Learning**: Live coding workshops where you build real projects from scratch.
  * **Networking**: Opportunities to meet seniors and batchmates to team up for hackathons and projects.
* **Fully Responsive Layout**: Optimized for seamless viewing and usage across mobile phones, tablets, and desktops.

---

## 🛠️ Technologies Used

* **HTML5** — Website structure and semantic content.
* **CSS3** — Styling, color schemes, spacing, and layout design.
* **JavaScript (JS)** — Interactive elements, form handling, and dynamic behaviors.
